# SwarmLens MagicPath design reference

Export/reference copy of the approved MagicPath prototype.

## Important

These files are a **visual implementation reference only**.

Do not treat hardcoded timestamps, ranks, scores, detector values, evidence rows,
summaries, analyst interpretations, or social-process hypotheses in these
components as application data.

The frozen SwarmLens Stage 1–4 artifacts in the main repository remain the
source of truth for research/data content.

Codex may refactor this prototype substantially when implementing the real
frontend. Preserve the visual language and interactions where practical rather
than copying prototype markup blindly.

## Visual reference

- Newsreader: headings and editorial/interpretive prose
- IBM Plex Sans: controls, labels, navigation, metadata
- IBM Plex Mono: provenance/evidence IDs
- Off-white canvas
- Deep/muted green structural palette
- Communication: muted blue
- Intention: muted red
- Participation: muted amber/gold
- Action type: muted purple
- Hollow timeline markers when unselected; filled green when selected
- Fine borders, little/no shadow, generous whitespace
- Approximately 65/35 evidence-to-interpretation layout on detail screen
